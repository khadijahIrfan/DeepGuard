DeepGuard — Multimodal Misinformation Detection System

DeepGuard is a Final Year Project (BS Software Engineering) designed to combat online misinformation, fake news, and manipulated media using Explainable Artificial Intelligence (XAI) and multi-modal neural network fusion.

System Capabilities: Text analysis via DistilBERT, DeepFake image detection via EfficientNetV2-S, EXIF metadata forensic audit, CLIP cross-modal context alignment check, and SHAP explainability.
